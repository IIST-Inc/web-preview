Authentication

FIDO2 authentication with custom scenario functions.

FIDO2/WebAuthn provides a standard path for phishing-resistant user authentication. IIST uses this path as the user-facing authentication layer, then supports companion hardware-rooted functions for device identity, secure actions, and lifecycle events.

IIST companion functions are separate from the FIDO2 standard and are designed around the customer's deployment scenario.

AI and Robotics Trust

Trust for robotics before action.
