Product Paths

Different form factors, one trust foundation.

All IIST product paths are built around the same idea: trust material should come from hardware, not only from stored secrets. Customers can start with the form factor that fits their project stage.

Stage: Fast deployment and workflow validation

Ankhor Key

Ankhor Key is IIST's portable hardware trust key concept for authentication, operator workflows, signing, and scenario-defined trust functions.

  • Hardware-rooted trust functions
  • Operator workflows
  • Signing support
  • Portable trust applications

Stage: Embedded product integration

SASe Chip

SASe Chip is IIST's Dynamic PUF-based secure co-processor platform for embedded systems. It helps device makers add hardware-rooted identity, trust separation, challenge-response behavior, and protected lifecycle functions to connected products.

  • Dynamic PUF foundation
  • Hardware-rooted identity
  • Multiple trust-function architecture
  • Embedded host integration
  • Secure lifecycle support

SASp Secure MCU
