SA

SASE01EPZS / SASe Chip

SASE01EPZS is IIST's Dynamic PUF-based secure co-processor platform for embedded systems. It helps device makers add hardware-rooted identity, trust separation, challenge-response behavior, and protected lifecycle functions to connected products.

  • Dynamic PUF foundation
  • Hardware-rooted identity
  • Multiple trust-function architecture
  • Embedded host integration
  • Secure lifecycle support

SASp Secure MCU

SASp is IIST's secure MCU platform direction for customers who need hardware-rooted identity and programmable trust functions in a more integrated architecture.

  • Hardware-rooted identity
