Dynamic PUF

Secrets should be born, not stored.

Dynamic PUF uses silicon behavior as a source of hardware-rooted trust material. IIST uses this foundation to support unique device identity, multiple trust functions, challenge-response mechanisms, local protection, and secure lifecycle workflows.
